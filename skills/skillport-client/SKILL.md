# SkillPort 클라이언트

# Must

## Scope

- SkillPort MCP가 연결된 새 사용자 작업마다 이 스킬을 사용해 후보를 검색한다.
- SkillPort MCP가 연결되지 않은 환경에서는 이 스킬을 사용하지 않는다.
- SkillPort의 등록·수정·삭제 요청에서는 검색 이후 이 조회용 스킬로 관리 작업을 수행하지 않는다.

## 조회

- 새 작업을 시작하면 작업을 설명하는 짧은 검색어로 `search_skills`를 한 번 호출한다.
- 검색 결과의 이름·설명·태그·호환성·의존성을 기준으로 현재 작업에 맞는 스킬만 선택한다.
- 버전 비교가 필요한 경우에만 `get_skill_version`으로 선택한 스킬의 버전을 확인한다.
- 선택한 스킬의 본문은 `get_skill`의 `name`으로 가져온다. 특정 버전이 필요한 경우에만 `version`을 지정한다.
- SkillPort 도구가 보이지 않거나 조회가 실패하면 연결·조회 실패를 알리고 일반 방식으로 진행한다.

# Must NOT

- 관련 스킬이 없다는 이유로 다른 스킬의 본문을 임의로 가져와서는 안 된다.
- 모든 등록 스킬의 본문을 미리 가져와서는 안 된다.
- 의존 스킬은 메타데이터에 있다는 이유만으로 자동 로딩해서는 안 된다.
- 요청 대상이나 범위가 바뀌지 않았다면 같은 작업에서 검색을 반복해서는 안 된다.
- 동일 작업에서 이미 확인한 동일 버전의 본문을 반복 조회해서는 안 된다.
- 조회에 실패한 스킬의 내용을 추측해서는 안 된다.

# Flow

1. 새 사용자 작업을 받으면 `search_skills`로 후보 메타데이터를 확인한다.
2. 검색 결과에서 현재 작업에 맞는 스킬이 있는지 판단한다.
3. 일치하는 후보가 있을 때만 해당 본문을 가져와 현재 작업에 적용한다.

# Definition of Done

## Verification

- SkillPort가 연결된 새 작업에서는 본문 필요 여부와 관계없이 검색이 한 번 수행된다.
- 스킬이 필요한 작업에서는 선택한 스킬의 본문만 로딩된다.
- 후보가 없거나 조회에 실패한 경우에는 확인되지 않은 스킬 지침을 적용하지 않는다.
