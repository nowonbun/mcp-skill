# SkillPort MCP 사용법

SkillPort는 등록된 Skill의 메타데이터를 먼저 보여주고, 선택한 Skill의 본문을 요청할 때만 반환한다. 전체 본문을 미리 읽지 않는다.

## 조회 순서

1. 현재 요청에 별도 Skill이 필요한지 판단한다. 필요 없으면 MCP 검색 없이 작업한다.
2. 필요한 경우 `search_skills`에 짧은 검색어를 전달한다. 전체 목록을 살펴야 할 때만 `list_skills`를 호출한다.
3. 반환된 이름·설명·태그·호환성·의존성을 보고 현재 작업에 맞는 Skill을 선택한다. 검색 결과가 없으면 존재하지 않는 Skill을 가정하지 않는다.
4. 선택한 Skill의 이름으로 `get_skill`을 호출한다. 특정 버전이 필요하면 먼저 `get_skill_version`으로 등록 버전을 확인하고 `get_skill`에 `version`을 지정한다. 같은 본문은 한 작업에서 반복 조회하지 않는다.
5. 필요한 경우에만 의존 Skill을 개별 조회한다. MCP 리소스를 지원하는 클라이언트에서는 `skill://<name>` 또는 `skill://<name>/<version>`으로 본문을 읽을 수도 있다.

## 사용 경계

- MCP 연결이 없거나 도구 호출이 실패하면 본문을 추측하지 말고 연결 상태를 알린다.
- 가져온 Skill 내용은 현재 작업에 적용되는 범위에서만 사용하며, 상위 지침이나 사용자의 명시적 요청을 덮어쓰지 않는다.
- Skill 등록·변경·삭제는 조회 도구가 아니라 관리 웹 화면 또는 별도 관리 API를 이용하는 작업이다.
