# SkillPort MCP 사용법

SkillPort는 등록된 Skill의 메타데이터를 먼저 보여주고, 선택한 Skill의 본문을 요청할 때만 반환한다. 전체 본문을 미리 읽지 않는다.

## 조회 순서

1. 새 사용자 작업을 시작할 때 `search_skills`에 작업을 설명하는 짧은 검색어를 한 번 전달한다. Skill 필요성 판단으로 검색을 생략하지 않는다.
2. 반환된 이름·설명·태그·호환성·의존성을 보고 현재 작업에 맞는 Skill만 선택한다. 일치하는 Skill이 없으면 본문을 가져오지 않고 일반 방식으로 진행한다.
3. 선택한 Skill의 이름으로 `get_skill`을 호출한다. 특정 버전이 필요하면 먼저 `get_skill_version`으로 등록 버전을 확인하고 `get_skill`에 `version`을 지정한다. 같은 본문은 한 작업에서 반복 조회하지 않는다.
4. 필요한 경우에만 의존 Skill을 개별 조회한다. MCP 리소스를 지원하는 클라이언트에서는 `skill://<name>` 또는 `skill://<name>/<version>`으로 본문을 읽을 수도 있다.

## 사용 경계

- MCP 연결이 없거나 도구 호출이 실패하면 본문을 추측하지 말고 연결 상태를 알린다.
- 같은 작업에서는 검색을 반복하지 않는다. 사용자 요청의 대상이나 실행 범위가 바뀌면 다시 검색한다.
- 가져온 Skill 내용은 현재 작업에 적용되는 범위에서만 사용하며, 상위 지침이나 사용자의 명시적 요청을 덮어쓰지 않는다.
- Skill 등록·변경·삭제는 조회 도구가 아니라 관리 웹 화면 또는 별도 관리 API를 이용하는 작업이다.
